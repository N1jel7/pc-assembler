Логика выбора компонентов

Нажимаешь на слот в сборке → открывается каталог компонентов с нужным типом.

1. Выбери сборку

Создай новую или открой готовую.

2. Выбери компонент

Откроется отфильтрованный каталог.

3. Вернись обратно

Выбранная деталь встанет в нужный слот.

4. Сохрани результат

После успешного заполения всех позиций сборка сохранится в базу данных
